# birki 💻

My personal website

## Local Development 🔨

Instructions for building and testing locally

### Run

```shell
npm ci
npm run build
npm run dev
```

### Build 🏗️

```shell
npm run build
```

### Typecheck

```shell
npm run typecheck
```

## Deploy to GitHub Pages 🚀

When you merge a pull request, or push to the `main` branch, GitHub Actions will build `dist/` and deploy it with GitHub Pages Actions.

Icons are local inline SVGs.
